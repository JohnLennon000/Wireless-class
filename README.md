# Школьное тестирование по локальной сети

Система работает без интернета. Она состоит из трёх частей:

- **Компьютер учителя** запускает сервер (`server/server.py`).
- **Ноутбуки учеников** (ICL RAYbook, Windows 7) открывают тест в браузере.
- **Wi-Fi точка Cisco** соединяет все устройства.

## Что делает система

- Ученик проходит тест. Результат сразу приходит на компьютер учителя.
- Учитель видит в реальном времени, какие ноутбуки в сети (обновление раз в секунду).
- Учитель видит, кто отвечает на вопросы, сколько вопросов отвечено и сколько времени осталось.
- Если связь пропала в конце теста, ноутбук хранит результат и отправляет его, когда связь вернётся.
- Результаты сохраняются в файл `server/data/results.json`. Перезапуск сервера их не удаляет.
- Учитель может скачать результаты в CSV (открывается в Excel).

## Как запустить

1. Установите Python 3.6 или новее на компьютер учителя. Дополнительные пакеты не нужны.
2. Подключите компьютер учителя к сети точки доступа.
3. Откройте папку `server` и запустите `start.bat` (или `python server.py`).
4. В окне сервера найдите строку «Для ноутбуков». Пример: `http://192.168.10.2:8080/`.
5. Откройте панель учителя: `http://localhost:8080/teacher`.
6. На каждом ноутбуке откройте адрес из шага 4. Введите номер ноутбука (1–99). Ноутбук запомнит номер.

Запуск с параметрами: `python server.py --port 8080 --devices 20 --pin 1234`

| Параметр | Значение |
|---|---|
| `--port` | Порт сервера. По умолчанию 8080. |
| `--devices` | Сколько ноутбуков показывать в списке заранее. Ноутбук, который ещё не подключался, виден как «не в сети». |
| `--pin` | PIN для панели учителя с другого компьютера. С самого компьютера учителя PIN не нужен. |
| `--show-key` | Показать ученику разбор ответов после теста. По умолчанию выключено. |

## Настройка сети

- Дайте компьютеру учителя **фиксированный IP-адрес** (например, `192.168.10.2`). Иначе адрес сервера изменится.
- Если в сети нет DHCP, задайте ноутбукам IP вручную или включите DHCP на точке доступа.
- Windows может спросить о доступе в сеть при первом запуске. Разрешите доступ для **частной сети**.
- Если ноутбуки не открывают адрес, проверьте брандмауэр Windows на компьютере учителя. Порт 8080 (TCP) должен быть открыт для входящих подключений.

## Структура

```
server/
  server.py          сервер (только стандартная библиотека)
  start.bat          запуск в Windows
  static/
    test.html        исходный тест (без изменений)
    net.js           сетевой модуль для ноутбуков (ES5, для старых браузеров)
    teacher.html     панель учителя
  data/results.json  результаты (создаётся сам)
```

## Ограничения

- Ответы к вопросам находятся в коде страницы `test.html`. Ученик может найти их через инструменты разработчика. Для честного экзамена перенесите проверку ответов на сервер.
- Тест написан на современном JavaScript. Старые браузеры Windows 7 (Internet Explorer 11) его не запустят. Нужен Chrome 109 или Firefox ESR 115.
- Сервер не шифрует данные. Используйте закрытую сеть без выхода в интернет.
